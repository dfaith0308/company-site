## 2026-10-14 / 가격 표기 — "오픈 이벤트 기간 무료 (정가 월 29,000원)" (대표 결정)

## 2026-10-14 / 내세우는 것 — "더 싸게 구해드립니다" (대표 결정)
- 상황: 기존 화면은 "수익·원가"를 앞세웠다. 대표가 만나본 사장님들은 남는 돈보다 당장 식자재를 싸게 사는 데 먼저 움직인다.
- 결정: 입구는 가격. 순서는 ① 쓰던 식자재를 알려주면 더 싸게 구해드림 ② 회원가 + 장바구니 추가 할인 ③ 발주요청. 원가·돈 관리는 "싸게 산 다음" 칸으로 내린다. 가격·상품 수로 쇼핑몰과 겨루지 않는다.
- 이유: ①은 쇼핑몰과 방향이 반대라 겹치지 않고, 상품 수가 적어도 성립하며, 지금 바로 할 수 있다. ③은 지역 유통업체가 모여야 해서 "지역별로 순서대로 엽니다"로만 적는다.
- 재검토 시점: 가입 수·전표 접수 수를 본 뒤

## 2026-10-14 / "최대 N% 할인"은 아직 쓰지 않음 (Claude Code 판단)
- 상황: 대표는 "최대 49%"처럼 크게 내세우고 싶어 한다. 식당OS 실측(10-14): 공개 상품 10개, 정가 대비 최대 17%, 장바구니 추가 10%.
- 결정: 숫자 한 줄 대신 실제 회원가 예시 3개와 "추가 할인 10%"를 적었다.
- 이유: 실제로 없는 할인율을 적으면 거짓 광고가 된다. 정가도 근거(실제 판매된 가격 등)가 있어야 한다.
- 재검토 시점: 그 할인율의 상품이 실제로 올라온 날 — 그때 "최대 N%"로 바꾼다.
