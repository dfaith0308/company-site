# 랜딩 관리자 — 전체 개요 (가칭 "랜딩OS")

## 왜 만드는가
식식이 랜딩페이지는 광고용이다. 그런데 지금은 글자 하나 바꾸려 해도 개발 작업이 필요하고, 광고 효과를 숫자로 볼 수 없다.
대표가 블로그 글 쓰듯 페이지를 만들고 고치고, 광고별 효과를 바로 볼 수 있어야 한다.
또 식식이뿐 아니라 D.FAITH의 다른 서비스(외주 포함)에도 같은 도구로 랜딩페이지를 만들 수 있어야 한다.

## 사용자
- 운영자(대표): 페이지를 만들고, 고치고, 게시하고, 광고 성과를 본다.
- 방문자(식당 사장님 등): 광고를 보고 들어와 페이지를 보고 버튼을 누르거나 문의를 남긴다.

## 전체 구조 (쉬운 설명)
- **관리자 화면** 하나에서 여러 사이트(식식이, 다른 서비스…)를 관리한다.
- 사이트 하나에 페이지 여러 개를 만들 수 있다. (예: 기본 페이지, 네이버 광고용 페이지, 인스타 광고용 페이지)
- 페이지는 **칸(블록)을 쌓아서** 만든다. 칸 종류를 고르고, 글·사진을 넣고, 순서를 끌어서 바꾼다.
- **게시하기**를 눌러야 실제 사이트에 반영된다. 그 전에는 미리보기로만 보인다.
- 방문·버튼 클릭·문의가 자동으로 기록되고, **광고별 성과표**로 보인다.

## 단계
| 단계 | 내용 | 끝나면 할 수 있는 것 |
|---|---|---|
| step1 | 페이지 만들기·고치기·게시 | 개발자 없이 문구·사진·칸 순서 변경 |
| step2 | 효과 측정 | 네이버·인스타·유튜브 광고별 방문·클릭·문의 수 확인 |
| step3 | 광고별 페이지·A/B 비교 | 문구 두 가지 중 어느 쪽이 잘 되는지 자동 비교 |
| step4 | siksiki.com 옮기기 | 지금의 식식이 랜딩을 새 관리자로 완전히 이전 |

## 이번에 만들지 않는 것
- 결제 기능 — 가입·결제는 각 서비스(restaurant.siksiki.com 등)에서 한다. 랜딩은 입구 역할만.
- 자유 배치 편집(사진을 아무 위치에 끌어다 놓기) — 칸을 쌓는 방식으로 충분하고, 휴대폰 화면이 깨질 위험이 크다.
- 여러 명이 동시에 편집 — 당분간 운영자는 대표 한 명.
- 블로그·게시판 기능 — 랜딩페이지 전용 도구로 한정.
- 다국어 — 한국어만.

## 완료 기준 (전체)
1. 대표가 관리자 화면에서 식식이 랜딩 문구를 바꾸고 "게시하기"를 누르면 1분 안에 siksiki.com에 반영된다.
2. 네이버·인스타·유튜브 광고 링크별로 방문자 수, "시작하기" 클릭 수, 문의 수를 표로 볼 수 있다.
3. 새 서비스용 랜딩페이지를 개발자 없이 30분 안에 새로 만들 수 있다.
