# step1 — 페이지 만들기·고치기·게시

## 왜 만드는가
지금은 문구·사진을 바꾸려면 개발 작업이 필요하다. 광고 문구는 자주 바꿔봐야 하는데 그럴 수가 없다.

## 사용자
운영자(대표). 관리자 화면에 로그인한 사람만 편집 가능.

## 화면과 흐름

### 1. 로그인
- 이메일로 로그인. 초대받은 계정만 들어올 수 있다.

### 2. 사이트 목록
- 카드로 사이트가 보인다: "식식이 (siksiki.com)", 나중에 다른 서비스.
- [새 사이트 만들기] 버튼.

### 3. 사이트 설정 (사이트마다 한 번 입력, 모든 페이지에 공통 적용)
- 사이트 이름, 주소(도메인)
- 로고, 탭 아이콘, 카톡·SNS 공유 미리보기 이미지
- 대표 색상(주 색, 버튼 색)
- 사업자 정보: 상호, 대표, 사업자등록번호, 통신판매업 번호, 주소, 이메일, 전화, 호스팅 업체
- 약관·개인정보처리방침 링크
- 카카오톡 채널 주소

### 4. 페이지 목록
- 표: 페이지 이름 / 주소 / 상태(게시됨·임시저장) / 마지막 수정일
- 예: "기본" → siksiki.com, "네이버 광고용" → siksiki.com/n1
- [새 페이지] [복제] [삭제]

### 5. 페이지 편집 화면
- 왼쪽: 칸 목록. 끌어서 순서 변경. 칸마다 [숨기기] [복제] [삭제].
- 가운데: 휴대폰 크기 미리보기. 칸을 누르면 그 칸 편집.
- 오른쪽: 선택한 칸의 입력칸(제목, 본문, 사진, 버튼 문구, 버튼 연결 주소).
- 글은 블로그처럼: 굵게, 색 강조, 줄바꿈 정도만.
- 사진: 끌어다 놓기 또는 [사진 올리기]. 올리면 자동으로 휴대폰용 크기로 줄여 저장.
- [+ 칸 추가] 누르면 칸 종류 목록이 나온다.
- 위쪽: [임시저장] [미리보기(새 창)] [게시하기]
- 페이지 설정: 페이지 제목, 검색 설명 문구, 공유 이미지(없으면 사이트 기본값).

### 6. 칸 종류 (처음에 만들 것)
| 칸 | 용도 (지금 식식이 페이지 기준 예) |
|---|---|
| 첫 화면 | 큰 제목 + 설명 + 버튼 1~2개 ("매출은 멋입니다…") |
| 단계 안내 | 01·02·03 순서 카드 |
| 카드 목록 | 아픈 점 목록, 기능 소개 (아이콘 선택 가능) |
| 글 + 사진 | "아무도 말 안 해주는 것" 같은 설명 칸 |
| 사진 한 장 | 큰 이미지 |
| 동영상 | 유튜브 영상 넣기 |
| 가격표 | 요금, 포함 항목 체크리스트, 안내 문구 |
| 권유 띠 | 짧은 문장 + 버튼 ("이미 공감되셨나요?") |
| 자주 묻는 질문 | 질문 누르면 답 펼쳐짐 |
| 후기 | 사장님 이름(가명)·가게·한 줄 후기 |
| 문의 양식 | 이름·연락처·가게명 등 입력 → 저장 (공급업체 입점 문의에 사용) |
| 하단 정보 | 사이트 설정의 사업자 정보 자동 표시 (직접 편집 X) |

- 칸마다 배경 선택: 흰색 / 연한 회색 / 주 색 / 어두운 색.

### 7. 게시
- [게시하기] 누르면 "지금 실제 사이트에 반영됩니다" 확인창 → 확인 → 1분 안에 반영.
- 게시할 때마다 버전이 저장된다. [지난 버전] 목록에서 골라 [이 버전으로 되돌리기].

## 데이터
- 사이트: 이름, 도메인, 로고, 색상, 사업자 정보, 약관 링크, 카톡 채널 주소
- 페이지: 사이트, 이름, 주소 경로(예: `n1`), 제목, 검색 설명, 공유 이미지, 상태
- 페이지 버전: 칸 목록 전체(칸 종류·순서·내용), 게시 시각, 게시한 사람
- 사진: 파일, 원본 이름, 크기, 올린 날짜
- 문의: 사이트, 페이지, 입력값(이름·연락처 등), 개인정보 동의 여부, 받은 시각, 처리 상태(새 문의/연락함/완료)

## 규칙
- 게시하기 전에는 실제 사이트에 절대 반영되지 않는다. (임시저장 ≠ 게시)
- 사업자 정보는 사이트 설정에서만 고친다. 페이지마다 다르게 적을 수 없다.
- 모든 페이지는 휴대폰 화면 기준으로 보인다. PC에서는 가운데 정렬.
- 문의 양식에는 개인정보 수집·이용 동의 체크가 반드시 있고, 체크하지 않으면 보낼 수 없다.
- 문의가 들어오면 대표 이메일(선택: 카톡 알림은 나중)로 알림.
- 실제 사이트는 빨라야 한다: 휴대폰에서 첫 화면이 2초 안에 보여야 한다.

## 예외 상황
- 제목이 비어 있는 칸 → 게시하기 누르면 "비어 있는 칸이 있습니다" 표시하고 해당 칸으로 이동.
- 버튼 연결 주소가 비어 있음 → 게시 막음.
- 같은 주소 경로(`n1`)를 두 페이지가 쓰려 함 → "이미 쓰는 주소입니다".
- 사진이 너무 큼(20MB 초과) → "사진이 너무 큽니다" 표시.
- 게시 실패 → "반영하지 못했습니다. 다시 눌러주세요" + 실제 사이트는 이전 상태 그대로 유지.
- 없는 주소로 들어온 방문자 → 사이트 기본 페이지로 보냄.

## 이번에 만들지 않는 것
- 효과 측정·광고 성과표 → step2
- A/B 비교 → step3
- siksiki.com 실제 이전 → step4 (step1은 테스트 주소에서 확인)
- 문의 카톡 알림 → 카톡 알림톡은 별도 계약·비용이 필요해서 이메일로 시작
- 칸 디자인 세부 조정(글자 크기·여백 직접 입력) → 정해진 스타일 안에서만 고르게 해서 페이지가 망가지지 않게 한다

## 완료 기준
1. 관리자 화면에서 지금 식식이 랜딩과 똑같은 페이지를 칸을 쌓아 만들 수 있다.
2. 문구·사진을 바꾸고 [게시하기]를 누르면 1분 안에 테스트 주소에 반영되고, [되돌리기]로 이전 버전으로 돌아간다.
3. 문의 양식으로 보낸 내용이 관리자 화면 [문의] 목록에 보이고 대표 이메일로 알림이 온다.
