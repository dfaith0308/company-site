# step2 — 효과 측정 (광고 성과표)

## 왜 만드는가
광고비를 쓰는데 어느 광고에서 사람이 오고, 누가 "시작하기"를 눌렀는지 모른다. 잘 되는 광고에 돈을 더 쓰고 안 되는 광고는 끄려면 숫자가 필요하다.

## 사용자
운영자(대표).

## 화면과 흐름

### 1. 광고 링크 만들기 (사이트 → [광고 링크])
- [새 광고 링크] → 매체 고르기(네이버 / 인스타·페이스북 / 유튜브 / 카카오 / 기타), 광고 이름 입력(예: "9월 원가 문구"), 연결할 페이지 선택.
- → 광고에 붙여 넣을 주소가 만들어진다. [복사] 버튼.
- 이 주소로 들어온 방문자는 자동으로 "네이버 · 9월 원가 문구"로 분류된다.

### 2. 성과표 (사이트 → [성과])
- 기간 선택: 오늘 / 7일 / 30일 / 직접 선택
- 맨 위 요약: 방문자 수, "시작하기" 클릭 수, 문의 수, 클릭률(클릭÷방문)
- 표: 광고 링크별 한 줄
  | 매체 | 광고 이름 | 방문 | 시작하기 클릭 | 문의 | 클릭률 |
- 페이지별 표: 어느 페이지가 잘 되는지
- 칸별 도달률: 방문자 중 몇 %가 그 칸까지 내려 봤는지 → 어디서 나가는지 보인다
- 광고 링크 없이 들어온 방문(검색, 직접 입력 등)은 "직접·검색"으로 묶어서 보인다.

### 3. 광고 매체 연결 (사이트 설정 → [광고 추적 코드])
- 입력칸 3개: 네이버 광고 추적 ID / 메타(인스타) 픽셀 ID / 구글(유튜브) 태그 ID
- 입력만 하면 모든 페이지에 자동으로 붙는다.
- 이걸 넣어야 각 광고 관리 화면에서도 "전환"이 잡히고, 광고 매체가 알아서 잘 반응하는 사람에게 광고를 더 보여준다.

## 데이터
- 광고 링크: 매체, 광고 이름, 연결 페이지, 만든 날짜
- 방문 기록: 사이트, 페이지, 광고 링크(없으면 비움), 들어온 경로(네이버 검색 등), 휴대폰/PC, 시각, 방문자 구분값(개인 식별 불가)
- 행동 기록: 방문 기록, 종류(버튼 클릭 / 칸 도달 / 문의 제출), 어느 버튼·어느 칸, 시각
- 사이트 설정: 광고 추적 ID 3종

## 규칙
- 버튼 클릭은 자동 기록된다. 대표가 따로 설정할 필요 없다.
- 이름·전화번호 같은 개인정보는 방문 기록에 절대 저장하지 않는다.
- 운영자(대표)의 방문은 통계에서 뺀다(관리자에 로그인된 상태의 방문 제외).
- 성과표 숫자는 최소 1시간 단위로 갱신된다.

## 예외 상황
- 광고 추적 ID를 잘못 입력 → 형식 검사 후 "형식이 맞지 않습니다".
- 광고 차단 프로그램 쓰는 방문자 → 매체 쪽 숫자는 빠질 수 있다. 우리 성과표는 우리 기록 기준이라 더 정확하다. 이 차이를 성과표 아래에 한 줄 안내.
- 방문 0인 기간 → "아직 방문 기록이 없습니다".

## 이번에 만들지 않는 것
- 매출·가입 완료까지 추적 — 가입은 restaurant.siksiki.com에서 일어나서 그쪽 연결 작업이 필요. step2 이후 별도 설계.
- 광고비 불러와서 "1명 데려오는 데 얼마" 계산 — 각 광고 매체와 연결 계약·승인이 필요. 당분간 대표가 매체 화면에서 확인.
- 방문자 행동 녹화(화면 녹화 도구) — 개인정보 부담.

## 완료 기준
1. 네이버·인스타·유튜브용 광고 링크를 관리자에서 만들고 복사할 수 있다.
2. 그 링크로 들어와 "시작하기"를 누르면 1시간 안에 성과표 해당 줄 숫자가 올라간다.
3. 대표가 로그인한 상태로 들어간 방문은 성과표에 잡히지 않는다.
