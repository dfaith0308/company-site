# step3 — 광고별 페이지·A/B 비교

## 왜 만드는가
"매출은 멋입니다" 문구와 다른 문구 중 어느 쪽이 사장님을 더 많이 움직이는지 감으로 정하지 않고 숫자로 정하기 위해서.

## 사용자
운영자(대표).

## 화면과 흐름
- 페이지 편집 화면 → [비교 실험 만들기]
- 지금 페이지를 A로 두고 B가 자동 복제된다. B에서 바꾸고 싶은 칸만 고친다.
- 나누는 비율 선택(기본 50:50).
- [실험 시작] → 같은 주소로 들어온 방문자가 A 또는 B를 보게 된다. 한 번 A를 본 사람은 다시 와도 A.
- 성과표에 실험 칸: A/B 각각 방문, 클릭, 문의, 클릭률, 그리고 "B가 더 좋을 가능성 ○○%".
- [A로 확정] / [B로 확정] → 이긴 쪽이 기본 페이지가 되고 실험 종료.

## 데이터
- 실험: 페이지, A 버전, B 버전, 비율, 시작·종료 시각, 확정 결과
- 방문 기록에 "A/B 중 어느 쪽을 봤는지" 추가

## 규칙
- 한 페이지에 실험은 동시에 하나만.
- 실험 중에는 A를 직접 고칠 수 없다(비교가 틀어지므로). 고치려면 실험을 끝내야 한다.
- 방문 100명 미만일 때는 "아직 판단하기 이릅니다" 표시.

## 예외 상황
- 실험 중 페이지 삭제 시도 → "실험 중인 페이지입니다. 먼저 실험을 끝내세요."
- B를 하나도 안 고치고 시작 → "A와 B가 똑같습니다" 경고.

## 이번에 만들지 않는 것
- 3개 이상(A/B/C) 비교 — 방문자가 적을 때는 둘로 나눠야 결과가 빨리 나온다.
- 자동 확정 — 결과는 대표가 보고 누른다.

## 완료 기준
1. 첫 화면 제목만 다른 B를 만들어 실험을 시작할 수 있다.
2. 휴대폰 두 대로 들어가면 각각 A 또는 B가 보이고, 같은 휴대폰은 계속 같은 쪽이 보인다.
3. 성과표에서 A/B 숫자를 비교하고 [B로 확정]을 누르면 B가 기본 페이지가 된다.
